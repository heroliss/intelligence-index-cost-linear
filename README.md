# 智能水平与任务成本（线性横轴）

线上地址：[Intelligence vs. Cost](https://heroliss.github.io/intelligence-index-cost-linear/)。

GitHub Pages 零构建静态网页，用线性美元成本与实测耗时坐标比较 Artificial Analysis 的两套核心基准：**模型智能指数与每任务成本**、**编程智能体指数与每任务成本**。顶部页签共用占满窗口的工作区，支持**散点图、数据表、IRT 能力效用曲线、月度订阅回本测算与多模型深度剖析对比**五视图联动，页面无需纵向滚动，支持一键切换中文 / English 与深浅色主题。

## 查看与交互亮点

- **双向感知对比度主题与中英切换**：默认深色主题，右上角支持切换浅色主题及 `中 / EN` 界面语言（浏览器记住主动选择）。厂商代表色通过感知色彩空间双向校准，确保深色与浅色白底下均达到 WCAG AA（`≥ 4.5:1`）可读对比度；页面声明 `darkreader-lock` 避免插件二次反色。
- **五视图独立状态、开源筛选与 CSV 导出**：两个基准页签各自保留缩放、平移、横轴维度（成本 / 耗时）、开源/闭源权重筛选（`全部 / 开源 / 闭源`，自动重算开源帕累托前沿）、厂商聚焦、搜索、权重参数、订阅回本参数与多维对比组合；URL Hash 自动同步关键视图与筛选状态（兼容 `#models` 与 `#coding-agents`），数据表与订阅视图支持一键导出带 UTF-8 BOM 的 `.csv` 表格。
- **成本 / 耗时双线性横轴与同系列推理轨迹（Test-Time Scaling）**：
  - 散点图横轴支持在**每任务美元成本（USD）**与**每任务平均端到端耗时（分钟）**之间无缝切换，分别记忆缩放视野并实时绘制成本-智能或速度-智能帕累托前沿。
  - 开启**推理轨迹（Effort Trajectories）**或悬浮/锁定节点时，自动连线同一模型/智能体家族不同推理思考档位（`low → medium → high → xhigh / max`），直观揭示测试时算力扩展收益递减乃至过度思考（Overthinking）拐点。
  - 鼠标滚轮**以指针所在数据坐标为锚点**缩放横轴，`Shift`+滚轮缩放纵轴，`Ctrl`+滚轮双向等比缩放；触屏支持单指平移与**双指捏合缩放**；聚焦图区后支持方向键平移、`+ / -` 缩放、`Home` 重置、`Esc` 解锁。
- **智能标签碰撞避让（Semantic Zoom）**：默认开启“自动避让”，优先展示锁定/悬浮节点、性价比榜首、聚焦厂商及帕累托前沿标签，低成本密集区的重叠非前沿标签自动隐去并在放大视图后渐次浮现；也可一键切换展示全部标签或调节字号与距离。
- **科学的 IRT 胜率混合性价比模型与全前沿覆盖（`α ∈ [0, 25]`）**：
  - 结合多步任务串联达标率与项目反应理论（IRT）高分剩余失误率压缩，以 `50` 分为天然锚点（`U(50; α) ≡ 50`，消除高幂次数值坍缩），引入正则化基准渐近线 `C = 105`：
    - `α = 0`（纯成本）：`性价比 = 50 ÷ 每任务成本`，覆盖最低单价前沿端点；
    - `0 < α < 1`：凹函数边际递减，适合简单分类与跑批场景；
    - `α = 1`（经典线性）：逐比特精确等于 `指数 ÷ 每任务成本`；
    - `α > 1`（`C¹` 平滑过渡）：`U(s; α) = 50 × (s/50)^α × [55 / (105 − s)]^((α−1)²/α)`，在 `[0, 25]` 区间内完整覆盖从 `$0.005` 轻量模型、主力甜点档（默认 `α = 3`）直至 `60+` 分旗舰与最高分 SOTA 模型。
  - **最低能力门槛（`s_min`）**：支持按任务硬性准入要求过滤低分模型（低于门槛条目自动淡化并在性价比排序中置底）。
  - **跨视图联动**：散点图可开启**最优等性价比切线（Iso-Value Contour）**实时观察切点沿帕累托前沿滑移；数据表标记帕累托前沿、开源权重与 `#1` 榜首徽章，点击“图中定位”或“+对比”可一键跳转散点图或加入深度对比；权重曲线直接投射当前榜单全部帕累托节点并支持实测区间/全量程与对数纵轴切换。
- **客观免维护的「API 按量 vs. 月订阅回本线」测算**：
  - 鉴于各厂商月订阅（Pro `$20` / Max `$100` / Ultra `$200` 等）采用动态限流且不公开精确配额上限，页面不编造黑盒限额，而是基于实测单任务 API 均价精确反算**回本任务数（`月费 ÷ 单任务 API 成本`）**与**预计月度 API 账单（`月任务量 × 单任务成本`）**。
  - 支持一键切换 `Pro $20` / `Max $100` / `Ultra $200` 或自定义月费及个人预计月任务量，在专用**订阅回本视图**、节点悬浮/锁定卡以及散点图**垂直回本成本线（`回本线`）**中直观区分“API 按量更省”与“超订阅线（配额够用时订阅更划算）”，随每 2 小时数据更新自动适配所有新模型。
- **多维剖析对比视图（`剖析对比`）**：
  - 支持任选最多 4 个模型或编程智能体并排深度剖析（默认自动推荐 SOTA、旗舰、均衡与开源代表组合）：
    - **能力雷达与分项拆解**：模型页签绘制 Intelligence Index v5 六维支柱雷达图（`FrontierCode`、`Terminal 4.0`、`HLE Diamond`、`CritPt Agent`、`Science`、`Omniscience`）及全科幻觉率对比；编程智能体页签绘制三大实战子集雷达与 Prompt 缓存命中率。
    - **成本构成与尾部风险箱线图**：模型页签拆解单任务成本与输出 Token 中 `输入 Prompt / 推理思考 / 最终回答` 占比及端到端耗时；编程智能体页签绘制单任务成本分位数（`P05–P25–P50–P75–P95` 与均值 ◆）水平箱线图，直观呈现复杂代理任务的长尾账单风险与交互步数。
    - **核心指标并排对决表**：自动高亮每一维度的最优胜出项。

> 两套指数的任务口径不同，应分别在各自榜单内比较。编程智能体成本为基准任务的平均 API 费用，不代表个人订阅月费。性价比权重反映主观质量偏好，非官方实测收益。

## 数据更新与本地验证

数据保存在 `data/current.json`，由 GitHub Actions 每两小时（`17 */2 * * *`）自动检查更新，校验通过且内容变化时原子替换快照并部署 Pages；抓取失败时完整保留上一份有效快照。

本地预览（进入 `github-site` 目录）：

```sh
python -m http.server 8765
```

浏览器访问 `http://localhost:8765/`。使用 Node.js 24 运行回归测试或手动刷新数据：

```sh
node --test scripts/*.test.*
node scripts/fetch_data.cjs
```
