# 智能水平与任务成本（线性横轴）

线上地址：[Intelligence vs. Cost](https://heroliss.github.io/intelligence-index-cost-linear/)。

GitHub Pages 零构建静态网页，用线性美元成本与实测耗时坐标比较五大核心维度：**综合智能**、**前沿极限（剔除 90%+ 已饱和旧测试）**、**人类与审美（融合 LMArena 去水份盲测 + Design Arena 视觉审美 + GDPval 职业真实交付）**、**编程智能体**与**网络安全**。顶部页签共用占满窗口的工作区，支持**散点图、数据表、IRT 能力效用曲线、月度订阅回本测算与最多 8 项深度剖析对比**五视图联动，页面无需纵向滚动，支持一键切换中文 / English、深浅色主题、上游动态速览与状态链接分享。

## 查看与交互亮点

- **双向感知对比度主题、最新动态浮层与一键链接分享**：默认深色主题，右上角支持切换浅色主题、`中 / EN` 界面语言、查看 `最新动态`（同步 Artificial Analysis 上游最新评测更新）以及一键复制当前完整参数状态的分享链接。厂商代表色通过感知色彩空间双向校准，确保深色与浅色白底下均达到 WCAG AA（`≥ 4.5:1`）可读对比度；配备 SVG 矢量图标与 Web App Manifest，声明 `darkreader-lock` 避免插件二次反色。
- **五大基准独立状态、纵轴子项镜头（Y-Axis Lens）与高清导图/CSV 导出**：五个基准页签各自保留缩放、平移、横轴维度（成本 / 耗时）、**纵轴子项镜头**（如在`人类与审美`中一键切换只看 `LMArena 交流人味`、`纯网页与UI审美` 或 `GDPval 44职业真实交付`；在`前沿极限`中切换只看 `GDP-PDF 一次全过` 或 `Harvey 顶尖律所`）、开源/闭源与专项筛选、厂商聚焦、搜索、权重参数与订阅回本参数；支持 `Alt+1..5` 切换顶层基准页签、`1..5` 切换视图；散点图、权重曲线与雷达对比图支持导出 **2× Retina 高清 PNG**，数据表与订阅视图支持导出带 UTF-8 BOM 的 `.csv` 表格。
- **成本 / 耗时双线性横轴、同系列推理轨迹与历史演进时间轴**：
  - 散点图横轴支持在**每任务美元成本（USD）**与**每任务平均端到端耗时（分钟）**之间无缝切换，分别记忆缩放视野并实时绘制成本-智能或速度-智能帕累托前沿。
  - 开启**推理轨迹（Effort Trajectories）**或悬浮/锁定节点时，自动连线同一模型/智能体家族不同推理思考档位（`low → medium → high → xhigh / max`），直观揭示测试时算力扩展收益递减乃至过度思考（Overthinking）拐点。
  - 开启**历史演进（Time-Travel Frontier）**可拖动时间轴或点击 `▶ 回放演进` 动态重现过去 15 个月帕累托前沿的推进轨迹，并精确计算同等智能水平下的真实 **AI 降本倍率**。
  - 鼠标滚轮**以指针所在数据坐标为锚点**缩放横轴，`Shift`+滚轮缩放纵轴，`Ctrl`+滚轮双向等比缩放；`Shift`+单击散点直接加入对比组，锁定节点卡片支持一键 `去剖析 →`；触屏支持单指平移与**双指捏合缩放**；支持 `/` 快速搜索、`[ / ]` 沿帕累托前沿巡航、方向键平移、`+ / -` 缩放、`Esc` 解锁。
- **智能标签碰撞避让（Semantic Zoom）**：默认开启“自动避让”，优先展示锁定/悬浮节点、性价比榜首、聚焦厂商及帕累托前沿标签，低成本密集区的重叠非前沿标签自动隐去并在放大视图后渐次浮现；也可一键切换展示全部标签或调节字号与距离。
- **科学的 IRT 胜率混合性价比模型与全前沿覆盖（`α ∈ [0, 25]`）**：
  - 结合多步任务串联达标率与项目反应理论（IRT）高分剩余失误率压缩，以 `50` 分为天然锚点（`U(50; α) ≡ 50`，消除高幂次数值坍缩），引入正则化基准渐近线 `C = 105`：
    - `α = 0`（纯成本）：`性价比 = 50 ÷ 每任务成本`，覆盖最低单价前沿端点；
    - `0 < α < 1`：凹函数边际递减，适合简单分类与跑批场景；
    - `α = 1`（经典线性）：逐比特精确等于 `指数 ÷ 每任务成本`；
    - `α > 1`（`C¹` 平滑过渡）：`U(s; α) = 50 × (s/50)^α × [55 / (105 − s)]^((α−1)²/α)`，在 `[0, 25]` 区间内完整覆盖从 `$0.005` 轻量模型、主力甜点档（默认 `α = 3`）直至 `60+` 分旗舰与最高分 SOTA 模型。
  - **最低能力门槛（`s_min`）与单次预算上限（`c_max`）**：对称支持按任务硬性准入分数过滤低分模型，以及按单任务美元预算上限（如 `≤ $0.50` / `≤ $1`）排除高价模型——不满足约束的条目在散点图与数据表中自动淡化并在性价比排序中置底，直接选出预算内的最优主力。
  - **一模多榜全站画像与跨榜对比同步**：点击锁定任意模型卡片即可在一处总览其在**综合智能、前沿极限、人类与审美、网络安全**四大榜单的得分与全榜排名胶囊并支持一键跨榜定位；`剖析对比`视图内置**跨榜全站排名对比行**与 `同步跨榜选型` 按钮，一键将当前自选模型组带入其他榜单横向检验。
  - **跨视图联动与六列可视化数据表**：散点图可开启**最优等性价比切线（Iso-Value Contour）**实时观察切点沿帕累托前沿滑移；数据表包含**名称、厂商、指数、单次成本、平均耗时、加权性价比**六列双向排序，自动标记近期新发 `新`（14 天内）、帕累托 `前沿`、`开源` 与 `#1` 榜首徽章，点击“图中定位”或“+对比”可一键跳转散点图或加入深度对比；权重曲线直接投射当前榜单全部帕累托节点并支持实测区间/全量程与对数纵轴切换。
- **客观免维护的「API 按量 vs. 月订阅回本线」与「轻重混合路由模拟」**：
  - 鉴于各厂商月订阅（Pro `$20` / Max `$100` / Ultra `$200` 等）采用动态限流且不公开精确配额上限，页面不编造黑盒限额，而是基于实测单任务 API 均价精确反算**回本任务数（`月费 ÷ 单任务 API 成本`）**与**预计月度 API 账单（`月任务量 × 单任务成本`）**。
  - 内置**混合路由模拟器（Cascading Router）**，支持测算“日常主力模型 + 疑难兜底旗舰”按任意比例分流后的混合单次成本、节省比例及与月订阅的盈亏对比。
- **主视觉大尺寸雷达与多云比价剖析视图（`剖析对比`）**：
  - 支持任选最多 **8 个**模型、智能体或网络安全评测条目并排深度剖析（配备可即时搜索多选的添加面板、`前沿全览 (8)` 跨档位一键抽样、几何穿透雷达拾取、单击锁定置顶、一键复制 Markdown 表格与 2× Retina 高清 PNG 导图）：
    - **三合一高分辨主视觉对比引擎（`微距去底雷达` · `分轴微距跑道` · `胜负分差 Δ`）**：针对顶尖前沿模型分差相近的痛点，主视觉区默认采用**微距去底雷达图**（自动剥离圆心低分空白死区，并支持切换**分轴独立极值归一化**与 `0–100` 全量程），同时支持一键切换为**分轴微距跑道图**（水平对齐独立截取每项局部区间，将 `0.5%–2%` 的毫厘差距放大十余倍并标注榜首领先幅度）与**胜负分差 Δ 图**（可任选组内均值、榜首或任意指定模型为中央 `0` 基准轴，直观展示 `+Δ / −Δ` 净胜负条）；下方细分卡片自动按单项名次由高到低排序并附微距比例底条。`综合智能`与`网络安全`支持基准六维与六大行业切换；`前沿极限`支持未饱和六维与专项实验室切换；`人类与审美`支持人类体感六维与 Design Arena 视觉审美五维切换；`编程智能体`展示四维实战基准与缓存命中率。
    - **成本构成、安全防护拒答率、多云 API 服务商比价与尾部风险箱线图**：模型页签拆解 `输入 Prompt / 推理思考 / 最终回答` 成本占比、端到端耗时及多云托管服务商（DeepInfra、Together AI、Modal 等）实测比价；网络安全页签展示**安全评测拒答率对比**、耗时与多云比价；编程智能体页签绘制单任务成本分位数（`P05–P25–P50–P75–P95` 与均值 ◆）水平箱线图。
    - **核心指标并排对决表**：自动高亮每一维度的最优胜出项。

> 三套指数的任务口径不同，应分别在各自榜单内比较。各榜单成本均为基准任务的平均 API 费用，不代表个人订阅月费。性价比权重反映主观质量偏好，非官方实测收益。

## 数据更新与本地验证

数据保存在 `data/current.json`，由 GitHub Actions 每两小时（`17 */2 * * *`）自动同步 Artificial Analysis、LMArena（HuggingFace 官方数据集接口）与 Design Arena 公共排行榜接口，校验通过且内容变化时原子替换快照并部署 Pages；外部竞技场接口临时波动时自动无损回退至上一份有效缓存，绝不阻断核心定时任务。

本地预览（进入 `github-site` 目录）：

```sh
python -m http.server 8765
```

浏览器访问 `http://localhost:8765/`。使用 Node.js 24 运行回归测试或手动刷新数据：

```sh
node --test scripts/*.test.*
node scripts/fetch_data.cjs
```
