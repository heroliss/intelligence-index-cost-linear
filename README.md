# 智能水平与任务成本（线性横轴）

线上地址：[Intelligence vs. Cost](https://heroliss.github.io/intelligence-index-cost-linear/)。

GitHub Pages 零构建静态网页，用线性美元成本坐标比较 Artificial Analysis 的两套核心基准：**模型智能指数与每任务成本**、**编程智能体指数与每任务成本**。顶部页签共用占满窗口的工作区，支持**散点图、数据表与 IRT 能力效用曲线**三视图深度联动，页面无需纵向滚动，支持一键切换中文 / English 与深浅色主题。

## 查看与交互亮点

- **双向感知对比度主题与中英切换**：默认深色主题，右上角支持切换浅色主题及 `中 / EN` 界面语言（浏览器记住主动选择）。厂商代表色通过感知色彩空间双向校准，确保深色与浅色白底下均达到 WCAG AA（`≥ 4.5:1`）可读对比度；页面声明 `darkreader-lock` 避免插件二次反色。
- **三视图独立状态与 URL 分享**：两个基准页签各自保留缩放、平移、厂商聚焦、搜索、权重参数与排序；URL Hash 自动同步关键视图与筛选状态（兼容 `#models` 与 `#coding-agents`），便于直接分享特定参数视图。
- **以指针为中心的平滑缩放与触屏捏合**：
  - 横轴始终保持真实线性美元刻度；左上角绿色区域标示优于全榜中位成本与中位指数的参考区间。
  - 鼠标滚轮**以指针所在数据坐标为锚点**缩放横轴，`Shift`+滚轮缩放纵轴，`Ctrl`+滚轮双向等比缩放；触屏支持单指平移与**双指捏合缩放**；聚焦图区后支持方向键平移、`+ / -` 缩放、`Home` 重置、`Esc` 解锁。
- **智能标签碰撞避让（Semantic Zoom）**：默认开启“自动避让”，优先展示锁定/悬浮节点、性价比榜首、聚焦厂商及帕累托前沿标签，低成本密集区的重叠非前沿标签自动隐去并在放大视图后渐次浮现；也可一键切换展示全部标签或调节字号与距离。
- **科学的 IRT 胜率混合性价比模型与全前沿覆盖（`α ∈ [0, 25]`）**：
  - 结合多步任务串联达标率与项目反应理论（IRT）高分剩余失误率压缩，以 `50` 分为天然锚点（`U(50; α) ≡ 50`，消除高幂次数值坍缩），引入正则化基准渐近线 `C = 105`：
    - `α = 0`（纯成本）：`性价比 = 50 ÷ 每任务成本`，覆盖最低单价前沿端点；
    - `0 < α < 1`：凹函数边际递减，适合简单分类与跑批场景；
    - `α = 1`（经典线性）：逐比特精确等于 `指数 ÷ 每任务成本`；
    - `α > 1`（`C¹` 平滑过渡）：`U(s; α) = 50 × (s/50)^α × [55 / (105 − s)]^((α−1)²/α)`，在 `[0, 25]` 区间内完整覆盖从 `$0.005` 轻量模型、主力甜点档（默认 `α = 3`）直至 `60+` 分旗舰与最高分 SOTA 模型。
  - **最低能力门槛（`s_min`）**：支持按任务硬性准入要求过滤低分模型（低于门槛条目自动淡化并在性价比排序中置底）。
  - **跨视图联动**：散点图可开启**最优等性价比切线（Iso-Value Contour）**实时观察切点沿帕累托前沿滑移；数据表标记帕累托前沿与 `#1` 榜首徽章，点击“图中定位”可一键跳转散点图锁定该模型；权重曲线直接投射当前榜单全部帕累托节点并支持实测区间/全量程与对数纵轴切换。

> 两套指数的任务口径不同，应分别在各自榜单内比较。编程智能体成本为基准任务的平均 API 费用，不代表个人订阅月费。性价比权重反映主观质量偏好，非官方实测收益。

## 数据更新与本地验证

数据保存在 `data/current.json`，由 GitHub Actions 每两小时（`17 */2 * * *`）自动检查更新，校验通过且内容变化时原子替换快照并部署 Pages；抓取失败时完整保留上一份有效快照。

本地预览（进入 `github-site` 目录）：

```sh
python -m http.server 8765
```

浏览器访问 `http://localhost:8765/`。使用 Node.js 24 运行回归测试或手动刷新数据：

```sh
node --test scripts/*.test.*
node scripts/fetch_data.cjs
```
